# Nana-s-code-and-imagery-repository
MATLAB code for DWT/IDWT, SDI, SAR time-series reconstruction &; WTD, along with datasets of precipitation,  Surface soil moisture, NDVI, and Sentinel-1.
This repository contains MATLAB code for SAR  signal processing, along with related multi-source datasets.
## Code Features
**Signal Processing**: Implementation of DWT (Discrete Wavelet Transform) decomposition and IDWT single-component inverse reconstruction.
**Index Calculation**: Implementation of the SDI index calculation.
**SAR Processing**: Implementation of time-series SAR signal reconstruction.
**Comparison Method**: Includes the MATLAB implementation of the WTD method.
## Data Contents
This repository includes the following datasets for a specific study area:
Precipitation data
Surface soil moisture data
NDVI dataset
Sentinel-1 dataset
